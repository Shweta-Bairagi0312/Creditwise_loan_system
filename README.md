# 💳 Credit Wise - Loan Approval Prediction

A Machine Learning project that predicts whether a loan application will be approved or not based on applicant details.

---

## 📌 Project Overview

This project analyzes loan application data and builds a predictive model to determine loan approval status. It helps in automating decision-making for financial institutions.

---

## ⚙️ Tech Stack

- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📊 Features

- Data Cleaning & Preprocessing
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Data Visualization
- Model Training & Evaluation
- Train-Test Split Implementation

---

## 🔍 Dataset Information

The dataset contains information like:
- Applicant Income
- Loan Amount
- Credit History
- Gender
- Marital Status
- Education
- Employment Status
